================================================================================
🚀 DEPLOYMENT OPTIONS
================================================================================

Vercel (Easiest):
  1. npm install -g vercel
  2. vercel --prod

Netlify:
  1. npm run build
  2. Go to netlify.com
  3. Drag dist/ folder

GitHub Pages:
  1. npm run build
  2. Push dist/ to gh-pages branch

Traditional Host:
  1. npm run build
  2. Upload dist/ via FTP

================================================================================
💡 QUICK CUSTOMIZATION
================================================================================

Change Colors:
  → Edit src/index.css (search for --warm-mustard)

Update Content:
  → Edit src/App.jsx (all text is there)

Replace Images:
  → Find <img> tags in App.jsx, update src URLs

Add Projects:
  → Add items to projects array in App.jsx (~line 133)

Add Navigation Links:
  → Edit navLinks array in App.jsx (~line 31)
