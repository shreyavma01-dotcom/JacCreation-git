## ❓ Frequently Asked Questions

**Q: Do I need to know React?**
A: Not really! Edit `src/App.jsx` like an HTML file. Most changes are just text.

**Q: Can I change colors?**
A: Yes! Update CSS variables in `src/index.css` - takes 2 minutes.

**Q: How do I add more projects?**
A: Add items to the projects array in `src/App.jsx` around line 133.

**Q: Can I use my own images?**
A: Absolutely! Replace image URLs in App.jsx with your own.

**Q: How do I deploy?**
A: Run `npm run build`, then upload `dist/` to any web host.

**Q: Is this mobile-friendly?**
A: Yes! Fully responsive with hamburger menu on mobile.
